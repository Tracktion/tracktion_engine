Detailed Description

The Engine is the central class for all tracktion sessions.

Create a Engine before creating any edits. Pass in subclasses of behaviours to customise how the engine behaves or pass nullptr to use the defaults. To get going quickly, just use the constructor that takes an application name, which uses default settings.

Typical declaration in your main component:

private:
tracktion_engine::Engine engine { ProjectInfo::projectName}

For Extended UI use:

◆ prepareForShutdown()

void engine::Engine::prepareForShutdown ( std::function< void()>  onReadyToDestroy)

Begins async shutdown: closes edits, releases plugins, and waits for plugin cleanup to complete.

Call this before destroying the Engine. The callback is invoked on the message thread when it's safe to destroy the Engine. If not called, the destructor falls back to synchronous cleanup.
