Detailed Description

template<typename Type, typename Constrainer = DummyConstrainer<Type>, auto MemoryOrderLoad = std::memory_order_seq_cst, auto MemoryOrderStore = std::memory_order_seq_cst>
struct engine::AtomicWrapper< Type, Constrainer, MemoryOrderLoad, MemoryOrderStore >

Wraps an atomic with an interface compatible with var so it can be used within CachedValues in a thread safe way.

Optionally supply a Constrainer to limit the value in some way.
