◆ musicalContextContentChanged()

void ARADocument::musicalContextContentChanged ( )

Notifies the plugin that the edit's tempo/key/chord content has changed so the musical context is re-read.

Driven at document level (Edit::sendTempoOrPitchSequenceChangedUpdates → ARADocumentHolder) so it also works when no ARA clips exist to forward the change, e.g. a browser/panel-only instance (QA 16550).

References musicalContext.
